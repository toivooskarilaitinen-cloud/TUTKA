# TUTKA

TUTKA on VAIMEA LABin kolmas instrumentti.

- **PULSSI** mittaa hetkeä.
- **MONITORI** mittaa järjestelmän tilaa.
- **TUTKA** etsii poikkeamaa.

TUTKA ei kokoa päivän tärkeimpiä uutisia. Julkaisukynnyksen ylittävät vain havainnot, jotka rikkovat perustellun odotuksen: `ANOMALY`, `SIGNAL`, `DIVERGENCE`, `RECORD WATCH` tai `ODDITY`.

Kategoriat ovat kulttuuri, teknologia, talous ja urheilu. Sivuston tämänhetkiset löydöt ovat käyttöliittymän esimerkkiaineistoa. Seuraava vaihe on lähteistetty keräys-, pisteytys- ja arkistointiputki.
